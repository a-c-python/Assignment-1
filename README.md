
# Indigenous Art Finder | Australia

## About the Project
Indigenous Art Finder is a web application designed to help users explore Indigenous Australian art, discover places where artworks can be viewed, and learn about the development of Indigenous art centres over time.

The project aims to make information about Indigenous art and cultural places easier to explore through a simple, accessible interface.

## How to Run the Project
Our project is a web-based app. It is accessible by going to the following link: https://cits1501ac.pythonanywhere.com/

## Features
- **Collections:** Browse and explore Indigenous artworks.
- **Places:** Discover places where Indigenous art can be viewed.
- **Development of Art Centres:** Explore information about the history and development of art centres.
- **Data Visualisations:** View graphs and statistics about art locations and their development over time.

## Technologies Used
- HTML – webpage structure
- CSS – styling and layout
- JavaScript – interactive features and data visualisations
- Python and Flask – backend and web application functionality

## Project Structure
- `Templates/` – HTML templates for the website.
- `app.py` – Python file that runs the Flask application.
- `Ai log` – Records the AI prompts used during project development and how AI contributed to the project.
- `.gitignore` – Specifies files and folders Git should ignore.
- `Procfile` – Tells the hosting platform how to start the web application using Gunicorn.
- `requirements.txt` – Lists the Python packages required to run the application.
- `requirementsfordevelopment.txt` – Lists additional packages required for development and testing.
- `test_app.py` – Contains automated tests used to check that the application works as expected.

## Data Sources
Information about Indigenous artworks, art centres and cultural places was collected from publicly available sources. Source links are included in the datasets where available to help users locate the original information. 
Main sources include: 
- AIATSIS – https://aiatsis.gov.au/
- Collections WA – https://collectionswa.net.au/
- data.gov.au – https://data.gov.au/
- data.wa.gov.au – https://data.wa.gov.au/
- Revealed – https://www.revealed.org.au/

Data is provided for educational purposes. Users should consult the original sources for further information and check relevant copyright, cultural protocols, and usage conditions before reusing material.
